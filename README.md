This is the production package for "Evaluating Agricultural Loans and Expenditure Allocation in Nigeria Using Double Machine Learning."

Use the README.pdf for instructions on use, additionally the code is thoroughly commented to enhance readability.

NOTE: data for the replication code can be sourced from the World Bank or at the Evans School Policy Analysis & Research Group github repository directly. For your convience we also provide a currated dataset which can be used to run all scripts in this repository at: https://drive.google.com/drive/folders/1kXMNiPrG0RK25XTm3gNratkzY15d3N_D?usp=sharing

NOTE: the python file scripts require multiple depenencies outlined in the README.pdf file. Additionally, python scripts have been heavily commented to improve readability, however some technical knowledge of python is still needed to utilize the scripts.
