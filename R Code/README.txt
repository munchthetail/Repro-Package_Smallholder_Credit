This file contains the neccessary R code to estiamte the Food Insecurity Experience Scale (FIES), using the standardized international scale for comparability across survey waves.

This code should be run prior to any other scripts in the reproduction package.

Cafiero, Carlo, Sara Viviani, and Mark Nord. 2018. “RM.weights: Weighted Rasch Modeling and Extensions Using Conditional Maximum Likelihood.” R package version 2.0. CRAN. Published April 20, 2018. https://CRAN.R-project.org/package=RM.weights
. DOI: 10.32614/CRAN.package.RM.weights
